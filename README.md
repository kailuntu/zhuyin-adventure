# 注音探險

[開始練習](https://kailuntu.github.io/zhuyin-adventure/)

給注音初學孩子使用的 RWD 練習網站：37 張聯想字卡、逐字拼讀示範、點選注音拼名字、語音答題與圖鑑收藏。題目使用全國圖鑑 0001–1025 的基本物種。

## 使用方式

1. 在手機、平板或電腦瀏覽器開啟上方網址。
2. 初學者可先選「注音字卡」，聽符號與看名字聯想。
3. 到「注音探險」，選擇「用點的拼注音」或麥克風答題。
4. 「教我注音怎麼拼」可逐字、逐步聽示範。

進度保存在目前裝置的瀏覽器，不跨裝置同步；清除網站資料可能刪除進度。本站沒有會員系統、密碼或錄音上傳儲存功能。瀏覽器語音辨識可能使用瀏覽器服務商的遠端服務，並依裝置、網路、權限而有不同支援程度。點選拼注音不需要麥克風。

## 教學與資料限制

注音多為程式轉換，只有部分明確覆寫與校對，尚未逐筆完成人工正音。37 張代表字卡的代表字音已比對教育部簡編本音讀索引。單個注音符號使用教育部錄音；結合韻與完整字音使用裝置合成語音，可能誤讀。語音答題比對文字及同音同調字，並非聲調聲學評分。

圖片与名稱來源為 PokeAPI 社群資料；本站不是寶可夢官方網站。素材來源與授權分別列於 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 發布與維護

在「注音字卡」選擇「列印／匯出 37 張字卡」，等候圖片載入後即可列印或另存為 PDF。使用 A4 直向、100% 縮放，關閉頁首與頁尾；每頁 6 張，共 7 頁，沿虛線裁切。首次匯出需要網路載入圖片，儲存的 PDF 可離線列印。

此儲存庫僅包含已檢查的網站發布檔，不含開發工具、環境變數、私人憑證、除錯記錄或測試資料。

GitHub Pages 使用 `main` 分支的根目錄發布；更新此分支後，GitHub 會重新部署。保持 `.nojekyll`，以及根目錄的 `index.html` 和各資料夾結構。

小幅文字調整可以在 GitHub 編輯對應檔案並提交。功能更新應在原始開發專案修改、測試，再執行本機的發布程序，避免下一次發布蓋掉線上手動修改。

發現問題可查看儲存庫 Actions 與 Settings → Pages。回退版本請用 Git 的 revert 建立回退提交，不需刪除儲存庫或強制推送。

請勿提交任何 API Key、密碼、`.env`、孩子個資或錄音。即使日後改成私人儲存庫，也無法收回其他人已下載的副本。
